## 可直接填写的详细说明

Surf Wax 是运行在 Chrome 侧边栏中的浏览器智能体。选择自己的模型服务并配置 API 凭据后，可以用自然语言让它阅读网页、填写表单、操作当前窗口中的标签页，并观察任务结果。

你可以连接多种模型 Provider，或使用自定义 OpenAI-compatible Endpoint。模型请求从扩展直接发送到你选择的服务；开发者不运营转发对话、网页内容的中转或同步服务器。

浏览器任务支持语义定位、跨源 iframe、表单与文件上传、画布输入、截图和 PDF，以及任务期间的只读网络请求、响应和控制台诊断。用户脚本有独立管理页，也可由智能体创建、编辑和启停；定义与启停状态保存在本机，启动或升级时恢复已启用脚本。使用用户脚本前需在 Chrome 扩展详情页开启 Allow User Scripts。

会话支持编辑消息、重试、分支、搜索、重命名和归档。历史较长时自动生成摘要，原始会话及完整工具结果仍保存在本机日志。正在执行任务的页面会显示透明防干扰层；可随时停止任务，关闭侧栏会中止本轮请求及工具。已经发生的网页操作不会回滚。

截图、PDF 和大型结果默认保存在会话内部。downloads 在安装时作为必需权限授予，明确保存文件时直接下载。下载失败或任务中断后仍保留内部产物，之后可以再次保存。

智能体可能读取任务涉及的网页内容、截图、文件、标签页信息、网络数据及工具结果，并将任务需要的内容发送给你选择的模型服务。扩展不会对这些内容脱敏、过滤或改写。配置和凭据保存在本机 Chrome 扩展存储，对话与工具日志保存在本机 IndexedDB。详情请阅读隐私政策。

需要 Chrome 138 或更高版本。安装后点击扩展图标打开侧栏，进入设置页选择 Provider 或自定义 Endpoint、填写凭据和模型，保存后即可输入任务。

## 权限用途说明

权限声明与 `manifests/store.json` 对齐：八项必需权限、无可选权限和全部网站 host access。`windows` API 的使用不对应额外的 `windows` Manifest 权限。

| 权限 | 必需 / 可选 | 提交用途说明 |
| --- | --- | --- |
| debugger | 必需 | 获取任务页面的可访问性与文档信息，完成真实浏览器输入、截图/PDF、跨源 iframe 操作及只读网络/控制台诊断。 |
| scripting | 必需 | 在正在操作的页面安装与释放透明防干扰层，启动恢复时清理遗留状态。 |
| sidePanel | 必需 | 显示原生 Side Panel 智能体会话界面。 |
| storage | 必需 | 在本机保存按 Provider 隔离的模型配置、API 凭据、用户脚本定义及启停状态。 |
| tabs | 必需 | 读取本轮窗口中标签页的标题/URL，确定目标并按任务创建、关闭或选择标签页。 |
| unlimitedStorage | 必需 | 保留本机完整 canonical event log、可恢复会话和较大的内部任务产物。 |
| userScripts | 必需 | 注册、编辑、启停并恢复用户脚本；使用前还需用户在 Chrome 详情页开启 Allow User Scripts。 |
| downloads | 必需 | 用户明确保存内部产物时调用 Chrome 下载能力；安装时授予，保存时不再申请权限。 |
| `<all_urls>` | Host access | 支持用户指定的跨网站任务、脚本匹配范围及自选模型端点。获准 host access 本身不会发起智能体任务。 |

扩展没有专用 Cookie/网页存储管理、浏览数据清理、请求改写、离线模拟、录制、Trace、视频或备用执行 host。通用网页求值和用户脚本仍能处理网页本身允许访问的数据，不能把删除这些专用命令表述为“扩展不可能接触相关数据”。

## 数据用途与执行功能说明

**单一用途草稿**：让用户通过自选 AI 服务在 Chrome 侧边栏中读取、操作并验证网页任务。

**数据用途草稿**：任务可能涉及用户输入、网页内容、浏览活动、截图、上传文件、通信内容及页面中可访问的身份或认证信息。模型配置与凭据保存在本机；完整会话、工具输入/输出/错误和内部产物保存在本机日志。用于模型上下文的数据直接发送到用户配置的模型端点。Models.dev 仅提供模型目录，目录请求不附带本地对话日志或凭据。具体数据类型应按最终功能和商店实际申报表填写。

**执行功能说明草稿**：智能体可以返回 run-code 的单个异步 JavaScript 函数表达式，通过扩展执行器调用绑定窗口/标签页的 page facade；也可在网页上下文求值，创建或编辑由 chrome.userScripts 注册的网页脚本。这些能力应向审核员明确说明，不能将材料写成“没有任何模型生成代码执行”。移除 devtools/offscreen host 和任意 Chrome/CDP 暴露，不等于移除网页代码执行或用户脚本。此说明描述实际功能，不代表已获得商店审核结论。

日志不自动过期；用户可删除会话或在设置页清空对话与日志。清空日志保留模型配置和凭据，清除扩展数据或卸载扩展可以清除它们。已保存到下载目录的文件需要单独删除。完整保留、传输与删除说明见 [隐私政策](../PRIVACY.md)。

## 审核员操作说明草稿

1. 使用 Chrome 138+ 安装候选 ZIP，确认根目录有 manifest.json。点击扩展图标打开真实 Side Panel。
2. 打开设置，选择 Provider 或 custom Endpoint，填入审核专用的有效模型与 API 凭据并保存。测试凭据通过商店后台审核说明单独提供，不写入仓库、截图或公开商店文案；提交者仍需准备这些信息。
3. 在普通网页上输入“列出当前窗口标签页，并阅读当前页面的标题与主要内容”。再在提交者指定的测试页面验证表单填入、定位后点击及结果观察。
4. 运行时在另一窗口切换焦点，确认操作仍绑定原窗口。关闭 owner Side Panel，核查请求和排队工具停止、页面防干扰层释放，再重新打开查看中断记录。
5. 请求截图或 PDF，确认默认作为内部产物。请求保存，确认直接下载且没有运行时权限申请；核对真实下载文件与内部产物一致，下载失败或中断后仍可保存已有产物。
6. 开启 Allow User Scripts，打开脚本管理页，创建匹配测试站点的脚本并启停。重启浏览器或更新同一条目后确认已启用脚本恢复、已禁用脚本保持禁用。

`release.spec.ts` 覆盖全新安装的必需权限、下载失败重试与中断；`native-download.spec.ts` 覆盖全新安装及升级后的真实文件保存、与内部产物逐字节一致，以及保存期间关闭真实侧栏后的恢复。审核说明列出的操作仍需最终候选版本实际核对。
