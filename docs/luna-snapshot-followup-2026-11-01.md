# 快照 frame 归属与 Token 复测

## 改动

- 子 frame 的文档插入其 iframe 行之后，并按实际语义层级缩进；未表示的 owner 会被标记，子文档仍保留。
- 默认快照省略逐行重复的、由角色推导出的操作提示；`fields` 仍可显式请求 `actions`。工具说明集中保留推导规则。
- 对子 frame 的占位提示，先证明本 frame 内文字和各级父 frame 宿主的完整包含，再输出原文；无法证明时标记未知。DOMSnapshot 的扁平树用于识别 open、closed 和嵌套 slot，不能仅凭页面 JS 的 `assignedSlot` 判断 closed shadow root。

## 验证

104 个单元测试文件、1490 项测试通过，构建、类型和工具文档检查通过。Chrome 155 扩展测试覆盖同源和跨源 frame、两层嵌套、同名诱饵、frame 替换、父级裁剪、open/closed slot 裁剪及分页。包含证明不检查其他元素遮挡，前后两次相同的证据也不能排除中间的 ABA 变化；普通系统字体等未能证明的提示仍可能为未知。

对之前真实 sequence 样本的 21 页快照，用 `o200k_base` 仅移除固定操作提示，完整 JSON 从 29,502 降至 27,024 tokens，减少 2,478（8.40%）。这是对旧样本的离线变换，未计入集中说明增加的提示词，也不代表实际计费或其他网页的普遍效果。

## 原生输入与短 frame 引用复测

后续修复覆盖原生输入框的重复值和区域快照归属、文档根默认 Arial 占位提示，以及 pinch zoom 时的视觉视口判断。frame 引用将 UUID 的 16 字节无损编码为 22 个 base64url 字符，生命周期校验保持不变。在前述通过样本的 18 个去重快照上离线替换引用，JSON 由 23,356 降至 22,672 个 `o200k_base` tokens，减少 684（2.93%）；这不是实际请求或计费的测量。105 个单元测试文件、1503 项测试及 9 项 Chrome 回归通过，包含跨 frame 和区域输入值、同名自定义字体及缩放视口。

固定开发源码再次运行同场景、同种子及同预算的真实模型样本，结果为超时、`classification=unknown`，业务和交互检查为 false。模型首次提交的顺序不符合任务要求，页面返回拒绝；随后继续重排但未在截止前完成。模型曾同时向 target 传入元素 ref 和短 frame ref，参数被拒绝且未派发；后续多次操作使用元素 ref，因而此样本没有证明模型成功使用短 frame ref，也不能将超时归因于短引用。报告保存在本地 `.dev/verification/snapshot-compact-model/reports/1793538688169-17-8644e6bd-c42b-4e6e-8062-e7232f973d1d.json`。

当前占位提示的静态绘制判定仍不能证明最终像素可见。Chrome 155 实验中，极小的 opacity 或多个祖先透明度叠加可使文字与隐藏时的截图相同，而证据仍标为 visible；同色背景、遮挡和混合也可能使结果不可见。不能根据这项检查宣称覆盖所有绘制情况。
