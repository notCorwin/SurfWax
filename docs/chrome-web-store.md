# Chrome Web Store 发布材料

0.3.0 的商店文案、八项必需权限（含 downloads）用途、数据与执行功能说明、审核操作和素材状态统一维护于 [商店材料草稿](store-listing.md)。最终提交、构建与测试证据见 [正式化验收记录](formalization-acceptance.md)。

版本以 package.json 为唯一来源，构建时写入 Manifest。正式 v* 版本 ZIP 与 SHA-256 不覆盖；autobuild 是经过验证后更新的 prerelease 测试渠道，不占用 Latest。文档和工作流本身不代表商店审核或最终验收已完成。
