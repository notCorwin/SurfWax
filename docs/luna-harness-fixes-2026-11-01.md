# 非快照问题修复与验证（2026-11-01）

本轮只提交 Harness、工具执行契约及会话滚动修复。快照采集、分页、DOM/AX 融合、框架标识和可见性由另一条工作线维护；它们的未提交改动没有纳入本轮提交或隔离验证。

## 实现

- **压缩与容量门禁**：checkpoint 保存实际压缩后估值；恢复时不把新增尾部当作已压缩基线。发送前检查最终 outgoing（包括工具、附件和浏览器状态），必要时强制压缩完整尾部；仍超窗口则不发送，原始历史保留。固定工具定义本身放不下时不反复压缩。
- **完成证据**：动作结果中带有有效页面身份、完整/增量模式及条目的页面观察，可作为观察证据；pending/unavailable 或单纯 dispatch 不算。完成提案使用同一用户配置的模型单独复核原始要求与实际观察，纯 answer 不能绕过网页任务核验。
- **全程操作账本**：在已有 canonical log 增量投影中保留有界参数、文件身份、任务状态和动作顺序，聚合所有尝试的计数；不只提供最近一段页面历史。较早的错误提交不能被后来正确文件覆盖。标签来自动作后观察，不假定它就是派发前不变的业务身份。
- **复核边界**：用户原始要求在压缩前保留；不完整要求不能放行。观察片段按预算递归投影，不先序列化整页再截断。复核请求也检查最终输入预算、受取消信号控制、记录成功/失败终态及已获得 usage；相同提案及证据复用上一判定。
- **错误契约**：SDK 参数拒绝明确记录 `invalid-tool-input`、`dispatched=false`、`effectUnknown=false` 和原始原因；评测不再因此把已结束任务误判为未知。真正写入后失联仍保留未知效果。
- **按键与即时定位**：named key 大小写规范化，支持 F1–F24；未知键在定位、聚焦及派发前拒绝。focus、blur、targeted press 的目标及 frame 解析不再隐式等待 40 秒，实际缺失立即失败；显式等待与状态核验保留独立语义。
- **文件传输**：`import_file_from_link` 移除文件名覆盖参数，保留 download 原名，否则使用响应 Content-Disposition 或 HTTP URL 文件名；不使用 blob 随机 ID 冒充原名。导入是只读网络操作，404 是已知失败，不制造未知业务写入。增加导入链接后上传的流程指引，避免把容器 HTML 当文件。
- **自动跟底**：替换失效控制层，将 following 意图与布局 offset 分开。明确向上输入暂停；ResizeObserver/MutationObserver 观察布局、RAF 合并更新。窗口重排及虚拟测量不再被误当用户上滚；保持原视觉 token 与会话布局。

复核增加了同模型的独立请求，是概率性一致性检查，不能代替业务端判分。模型仍可能读错、过度核验或给出错误判定；报告不把 `complete_goal` 被接受等同于业务成功。

## 隔离验证

为避免与快照工作线互相热更新，使用仅含本轮提交的独立主代理工作树、Vite 开发扩展及独立缓存。模型验证使用用户指定的 `gpt-6-luna` 和本机端点，不更换更强模型、不约束思考强度。

- 最终完整单元测试：97 文件、**1,358 项通过**。默认高并发运行曾使现有 8,000 条网络记录回放测试触发 5 秒超时；保留失败日志，以 `--maxWorkers=2` 重跑完整套件通过，未修改测试超时或断言。
- TypeScript 与针对本轮已提交工具注册表生成的工具文档检查通过。
- 原有浏览器目标模式两项回归、provider input usage 校准用例通过。
- 自动跟底的严格浏览器用例在隔离环境连续 **3 次通过**。包含底部继续向下滚、向下键、多个宽高重排、内容增长、主动上滚暂停、暂停后缩放保位、按钮恢复及恢复后增长；保留原有 `remaining <= 1`、增长 `>350px` 等断言。
- 增长测试先检查虚拟 spacer 与真实 turn 高度收敛，并在同一次页面调用中读基线和追加 400px。此前失败证明确有重测量使旧基线缩小 76px；没有用降低增长阈值或 sleep 掩盖它。
- 浏览器为 Chrome for Testing 155.0.8059.79，验证环境 Node 22.21.0；项目声明的 Node 24 由现有 CI 配置负责，未将本机验证描述成 Node 24 结果。
